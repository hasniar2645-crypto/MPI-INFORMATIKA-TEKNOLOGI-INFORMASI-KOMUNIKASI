LANGKAH 03

Materi Pokok

Struktur data adalah cara mengorganisasi data agar dapat digunakan secara efektif.

📋

Array

Kumpulan elemen sejenis yang disimpan berurutan dan diakses menggunakan indeks.

0
121
182
153
20
Contoh: daftar nilai [12, 18, 15, 20]. Indeks sering dimulai dari 0.
🥞

Stack (tumpukan)

Menggunakan prinsip LIFO (Last In, First Out): data terakhir masuk menjadi yang pertama keluar.

Data C · atasData BData A · bawah
Contoh: tumpukan piring atau fitur Undo.
🚶

Queue (antrean)

Menggunakan prinsip FIFO (First In, First Out): data yang masuk lebih dahulu keluar lebih dahulu.

ABC→
Contoh: antrean cetak dokumen atau antrean kantin.
🔗

Linked List

Kumpulan simpul (node). Setiap node menyimpan data dan tautan ke node berikutnya.

10 → 25 → 31 → null
Node tidak harus berada bersebelahan di memori.
🌳

Tree (pohon)

Struktur bertingkat yang terdiri dari root, parent, child, dan leaf.

A
BC
DEF
Contoh: susunan folder dan subfolder.
🕸️

Graph (graf)

Terdiri dari simpul (vertex) dan sisi (edge) yang menghubungkan simpul.

●──●
╲ ╱ │
●──●
Contoh: jaringan pertemanan atau peta jalan.
Ingat!

Pilih struktur data berdasarkan kebutuhan. Array cocok untuk data berindeks, stack untuk pola LIFO, queue untuk FIFO, tree untuk hierarki, dan graph untuk hubungan yang saling terhubung.
